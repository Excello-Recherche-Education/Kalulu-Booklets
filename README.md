# Kalulu-Booklets

Generator for the **Kalulu reading booklets**: small printable books, in A5
format, that follow the same progression as the
[Kalulu](https://github.com/Excello-Recherche-Education/Kalulu-Frontend) app,
produced as PDF straight from the language packs.

[Kalulu](https://github.com/Excello-Recherche-Education) is an open-source
educational app that helps children learn to read through the decoding
(grapheme–phoneme) method, developed by
[Excello Recherche & Éducation](https://github.com/Excello-Recherche-Education).

> **Status: first version.** The generator writes the base booklet of every
> booklet number a pack defines. The teacher's booklet, the booklet without
> writing pages and the printing imposition are still to come, and so is the
> covers' artwork. The pages carry the game's characters: the parakeet under the
> fluency test's speech bubble, beside two stopwatches, the penguin above the
> tables and the caterpillar on the writing pages (`src/kalulu_booklets/art/`,
> whose `LICENSE.md` says where each comes from).

## What it produces

A series of booklets per language, as PDF files ready to print:

- **A5 format** (148 × 210 mm), the size of a small exercise book;
- **the app's progression**: the booklets go through the lessons in the same
  order as the game, so a child reads on paper exactly the graphemes, syllables,
  words and sentences they have met on screen, and nothing they have not met
  yet;
- **one series per language pack**, generated by the same code for every
  language.

## Where the content comes from

Everything a booklet prints comes from the language packs, included here as a
git submodule:

| Folder | Repository | What it is |
|---|---|---|
| `kalulu-languages/` | [Kalulu-Languages](https://github.com/Excello-Recherche-Education/Kalulu-Languages) | Language packs (`fr_FR`, `es_AR`, `es_CO`, `es_UY`, `pt_BR`) |

Each pack's `language.db` (SQLite) is the single source of truth for the
progression: the numbered lessons, the grapheme–phoneme correspondences each
lesson introduces, and the words, syllables and sentences that become readable
along the way, and the booklets' own content. The generator reads nothing else
from a pack, apart from the fonts beside the packs. The database structure is documented in the packs' own
[SCHEMA.md](https://github.com/Excello-Recherche-Education/Kalulu-Languages/blob/main/SCHEMA.md).

Because the booklets and the app read the same pack, a change to a language
pack reaches both: there is no second copy of the content to keep in sync.

## Why this repository

The booklets used to be produced by an older script fed with a CSV assembled
for each country, plus a fair amount of manual work to get from the language
data to finished PDFs. This repository puts everything the booklets need in one
place (the code, the layout, the fonts and images, and a pinned version of
the language packs) so that anyone can regenerate them, for any language,
from a single command.

## Getting a working copy

```bash
git clone --recurse-submodules https://github.com/Excello-Recherche-Education/Kalulu-Booklets.git
cd Kalulu-Booklets
```

Forgot `--recurse-submodules`?

```bash
git submodule update --init
```

The language packs include every app sound, image and video, so the first
checkout downloads more than a gigabyte. The booklets only need the text data;
to save time and disk, a shallow checkout is enough:

```bash
git clone --recurse-submodules --shallow-submodules https://github.com/Excello-Recherche-Education/Kalulu-Booklets.git
```

## Updating the language packs

A submodule is a **pointer to one specific commit** of Kalulu-Languages, so a
given commit of this repository always generates the same booklets. To move to
the latest packs:

```bash
git submodule update --remote kalulu-languages
git add kalulu-languages
git commit -m "Bump language packs"
```

## Requirements

- Python 3.11 or newer
- Git

## Installing

```bash
python3 -m venv .venv
.venv/bin/pip install -e '.[dev]'
```

This installs [ReportLab](https://www.reportlab.com/) for the PDF and
[uharfbuzz](https://github.com/harfbuzz/uharfbuzz) (HarfBuzz) for text shaping:
the cursive font joins its letters through OpenType rules, which only a shaping
engine applies.

## Generating the booklets

```bash
.venv/bin/kalulu-booklets build fr_FR                         # the pack pinned in kalulu-languages/
.venv/bin/kalulu-booklets build ../Kalulu-Languages/fr_FR     # any pack folder, saved or not
.venv/bin/kalulu-booklets build fr_FR --booklet 1 --out /tmp/booklets
.venv/bin/kalulu-booklets build fr_FR --version teacher       # one version only
```

A bare locale reads the pack pinned in `kalulu-languages/`; a path reads any pack
folder (or its `language.db`), such as a Kalulu-Languages checkout the Prof Tool
has just saved to, so a change can be seen before it is committed. The pack is
only ever read.

Every booklet is written in each of its **versions**, one folder per version under
`build/<locale>/`. Every version has the same content; only the pages differ:

| Version | Folder, file | What changes |
|---|---|---|
| base | `base/<locale>-booklet-<n>.pdf` | the booklet itself |
| teacher | `teacher/<locale>-booklet-<n>-teacher.pdf` | before each chapter, a page with its title and its picture (the Look & Learn image the chapter names), under the same page number as the chapter page, so that a teacher's copy and the pupils' agree. "Version enseignant" on the cover |
| no writing pages | `no-writing/<locale>-booklet-<n>-no-writing.pdf` | without its writing pages |

The base and no-writing versions are also written **for printing**, as
`…-print.pdf`: A4 landscape, two A5 pages a side, in saddle-stitch order (the last
and the first, then the second and the second-to-last…), so that the sheets,
printed on both sides, folded and stapled, read in order. A booklet printed that
way has a multiple of four pages, which blank pages before the back cover make up.
The teacher's pictures need the pack's `look_and_learn/images/`, which are in Git
LFS: without them, the teacher version has no teacher pages, and the build says so.

Then comes a list of what to look at: what the pack asks for and the
booklet cannot print, such as a chapter with nothing in it, sentences that do not
fit the pages allowed, or a sentence its lesson cannot read yet. It also lists a
chapter that picks no sentence and has too few of its own to fill its pages: the
generator then prints sentences that hold none of the chapter's GPs, earlier
lessons' content, and says how many. None of it stops the build.

**The booklets are never committed**: `build/` is ignored. They are published as
a release instead, by the **Release Booklets** workflow (Actions → Release
Booklets → Run workflow). It runs the tests, then builds every language pack in
`kalulu-languages/`, and publishes them in one release, **one zip per language**:
`Kalulu-Booklets-<locale>.zip`. A release lists its files flat, with no folders,
so the folders are inside each zip: the language's PDFs, as the generator writes
them, and `build-notes.txt`, listing what that pack could not print as asked. By default it
builds the packs at the commit this repository pins. *languages_ref* builds from
another branch, tag or commit of Kalulu-Languages instead, for example `main`.
If one pack fails to build, nothing is published.

### What a booklet holds

The content of the booklets is edited in the **Booklets** tab of the
[Prof Tool](https://github.com/Excello-Recherche-Education/Kalulu-ProfTool) and
stored in the pack's `Booklet*` tables: see "The reading booklets" in the packs'
`SCHEMA.md`. In short:

- **chapters follow the app's lessons**, and say which booklet they are in.
  Every lesson has one, its first chapter; the chapters after it are optional
  ones, printed before the next lesson's. A lesson without a chapter gets its
  own: the lesson's graphemes, a title made of them ("L l"), the language's
  settings and the booklet of the chapter before it (booklet 1 for a pack with no
  chapter yet), as the Prof Tool makes it when it opens such a pack;
- each chapter page has its title (script on the left, cursive on the right), its
  syllables and words, then its sentences, in paragraphs that alternate script
  and cursive;
- a chapter prints as many syllables and words as its counts say: the ones picked
  for it first, in their order, the last ones left out when there are too many.
  When there are too few, the rest is chosen from the pack: the syllables and
  words readable at its lesson that hold one of its graphemes, booklet-only ones
  first, then in the pack's order. Exceptions are left out, and so are entries
  with no vowel, such as the `l` of `l'ours`. If even that falls short, what was
  chosen is repeated until the count is reached;
- the sentences fit on the page they start on (`SentencePages` 0), or take up to
  that many more pages; -1 prints none. A chapter that picks no sentence gets
  as many as fit, each whole and a paragraph of its own: the sentences readable
  at its lesson, those holding one of its graphemes first, booklet-only ones
  first within each, then in the pack's order. One that would run onto the
  next page is passed over for a shorter one, and one already printed in the
  booklet comes after the others;
- silent letters are printed in grey where the chapter asks for it, found from
  each word's grapheme-phoneme decomposition;
- then come the chapter's tables, stories, writing pages (on Seyès ruling,
  each model in black then in grey to trace over) and fluency test;
- blank pages are added before the back cover to reach a multiple of four, since
  a booklet is printed on folded sheets.

### Tests

```bash
.venv/bin/python -m pytest
```

They build a small pack from the schema in `kalulu-languages/schema/`, so the
submodule must be checked out.

## Fonts

The booklets print with the fonts of the language packs, kept in
Kalulu-Languages' [`fonts/`](https://github.com/Excello-Recherche-Education/Kalulu-Languages/tree/main/fonts)
folder: no copy of them is kept here. They are read from the Kalulu-Languages
checkout the pack is in (`../Kalulu-Languages/fonts` for
`../Kalulu-Languages/fr_FR`), or else from `kalulu-languages/fonts`.

| Font | File | Used for |
|---|---|---|
| Mulish, the version modified for Kalulu | `mulish/kalulu_mulish_{regular,bold,black}.otf` | script |
| Marelle | `marelle/Marelle-Regular.ttf` | cursive |

Both are under the SIL Open Font License 1.1; see `fonts/LICENSE.md` there.
The PDFs embed the letters they use, which the license allows.

**A language can replace any of the four**, the three weights of Mulish or
Marelle, with another font of that `fonts/` folder: the pack lists it in its
`BookletFonts` table and says what it replaces in `BookletSettings` (Kalulu-Languages'
`SCHEMA.md`). It is set in the
[Prof Tool](https://github.com/Excello-Recherche-Education/Kalulu-ProfTool):
Booklets, *Language settings*, *Fonts*. The font then prints everywhere the one
it replaces did. A font the pack names that is not in `fonts/` stops the build;
a letter a font cannot print is listed after it, since it comes out as the
font's empty box. A letter the font has no glyph for but can build from its
parts is printed that way: Marelle has no `á`, and prints it as `a` and an
accent.
