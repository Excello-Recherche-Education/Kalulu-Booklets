# Kalulu-Booklets

Generator for the **Kalulu reading booklets**: small printable books, in A5
format, that follow the same progression as the
[Kalulu](https://github.com/Excello-Recherche-Education/Kalulu-Frontend) app,
produced as PDF straight from the language packs.

[Kalulu](https://github.com/Excello-Recherche-Education) is an open-source
educational app that helps children learn to read through the decoding
(grapheme–phoneme) method, developed by
[Excello Recherche & Éducation](https://github.com/Excello-Recherche-Education).

> **Status: initial setup.** The repository holds the language packs and this
> README; the generator itself is still to be written.

## What it produces

A series of booklets per language, as PDF files ready to print:

- **A5 format** (148 × 210 mm), the size of a small exercise book;
- **the app's progression**: the booklets go through the lessons in the same
  order as the game, so a child reads on paper exactly the graphemes, syllables,
  words and sentences they have met on screen, and nothing they have not met
  yet;
- **one series per language pack**, generated by the same code for every
  language.

## Where the content comes from

Everything a booklet prints comes from the language packs, included here as a
git submodule:

| Folder | Repository | What it is |
|---|---|---|
| `kalulu-languages/` | [Kalulu-Languages](https://github.com/Excello-Recherche-Education/Kalulu-Languages) | Language packs (`fr_FR`, `es_AR`, `es_CO`, `es_UY`, `pt_BR`) |

Each pack's `language.db` (SQLite) is the single source of truth for the
progression: the numbered lessons, the grapheme–phoneme correspondences each
lesson introduces, and the words, syllables and sentences that become readable
along the way. The CSV exports next to it (`gp_list.csv`, `words_list.csv`,
`syllables_list.csv`, `sentences_list.csv`) carry the same data in flat form.
The database structure is documented in the packs' own
[SCHEMA.md](https://github.com/Excello-Recherche-Education/Kalulu-Languages/blob/main/SCHEMA.md).

Because the booklets and the app read the same pack, a change to a language
pack reaches both: there is no second copy of the content to keep in sync.

## Why this repository

The booklets used to be produced by an older script fed with a CSV assembled
for each country, plus a fair amount of manual work to get from the language
data to finished PDFs. This repository puts everything the booklets need in one
place (the code, the layout, the fonts and images, and a pinned version of
the language packs) so that anyone can regenerate them, for any language,
from a single command.

## Getting a working copy

```bash
git clone --recurse-submodules https://github.com/Excello-Recherche-Education/Kalulu-Booklets.git
cd Kalulu-Booklets
```

Forgot `--recurse-submodules`?

```bash
git submodule update --init
```

The language packs include every app sound, image and video, so the first
checkout downloads more than a gigabyte. The booklets only need the text data;
to save time and disk, a shallow checkout is enough:

```bash
git clone --recurse-submodules --shallow-submodules https://github.com/Excello-Recherche-Education/Kalulu-Booklets.git
```

## Updating the language packs

A submodule is a **pointer to one specific commit** of Kalulu-Languages, so a
given commit of this repository always generates the same booklets. To move to
the latest packs:

```bash
git submodule update --remote kalulu-languages
git add kalulu-languages
git commit -m "Bump language packs"
```
